# SVARNA — Prototipe Model Rumah

Aplikasi visualisasi konseptual rumah berbasis parameter ukuran. Hasil berupa denah SVG skematis dan tampilan massa eksterior 3D yang dapat diputar, bukan gambar kerja arsitektur.

## Terbitkan di GitHub Pages
1. Buat repository **svarna-model-rumah** dengan visibilitas **Public**.
2. Unggah isi folder ini (`index.html`, `.nojekyll`, `README.md`) **ke akar/root repository**, bukan folder tambahan.
3. Buka **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Pilih branch `main`, folder `/(root)`, klik **Save**.
5. Setelah terbit, URL biasanya `https://USERNAME.github.io/svarna-model-rumah/`, ganti USERNAME dengan nama akun GitHub.
6. Uji input dimensi, atap, simpan denah SVG dan tampak PNG dari browser.
7. Tambahkan tombol di halaman Model Rumah WordPress yang menuju URL hasil publikasi tersebut.

## Catatan
- Bekerja di browser tanpa API atau layanan AI berbayar.
- Denah hanya skema ruang, tidak divalidasi menurut standar desain teknis.
- Tampilan 3D adalah model eksterior konseptual, bukan denah 3D interior terpadu.
